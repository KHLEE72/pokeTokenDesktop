# Mac 테스트 안내 — PokeToken Desktop 0.3.3

macOS 14 이상에서 실행합니다. Apple 메뉴 → 이 Mac에 관하여에서 칩을 확인하세요. M1·M2·M3·M4 등 M 시리즈는 `arm64`, Intel 프로세서는 `x64` 파일을 사용합니다.

## 설치와 첫 실행

1. 전달받은 `.dmg` 파일을 열고 **PokeToken Desktop**을 **Applications(응용 프로그램)** 폴더로 옮깁니다.
2. 응용 프로그램 폴더에서 **PokeToken Desktop**을 실행합니다.
3. 이 버전은 테스트용 ad-hoc 서명만 사용하며 Apple의 개발자 인증·공증을 받지 않았습니다. 개발자 확인 경고가 나오면 전달받은 출처와 파일을 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기(Open Anyway)**에서 해당 앱의 실행을 허용할 수 있습니다. [Apple 안내](https://support.apple.com/en-us/102445)
4. 관리 화면과 화면 아래의 알이 나타나는지 확인합니다. 관리 화면을 닫아도 펫과 메뉴바 아이콘은 계속 실행됩니다. 종료는 메뉴바의 **종료**를 사용하세요.

앱이 손상되었다는 메시지나 실행 실패가 나오면 메시지·macOS 버전·칩 이름을 전달해주세요. 전체 시스템 보안 설정을 끌 필요는 없습니다.

## 사용량 연결

Claude Code·Codex의 기본 로컬 로그를 자동으로 찾습니다. 다른 경로를 사용하면 **설정 → 토큰 사용 기록 연결 → 폴더 추가**에서 연결하세요.

- Claude Code: `~/.claude/projects` 또는 설정한 `CLAUDE_CONFIG_DIR` 아래 `projects`
- Codex: `~/.codex/sessions` 및 `~/.codex/archived_sessions`, 또는 설정한 `CODEX_HOME` 아래 동일 폴더

처음 연결한 기존 사용량은 합계에만 표시됩니다. 연결 후 새로 쓰는 토큰부터 성장합니다. 기본 속도에서는 새 토큰 50만으로 부화합니다. 펫은 AI를 호출하지 않으며, 포켓몬 이미지를 처음 받을 때만 다운로드가 필요합니다.

## 확인할 동작

- 마우스로 누르면 매달리는 모습이 나오고, 끌어서 옮긴 뒤 높은 곳에서 놓으면 바닥까지 떨어져 착지하는지
- 창을 화면 위쪽에서 조금 내려 펫이 설 공간을 만든 뒤, 펫을 창 위에서 놓으면 테두리에 착지하는지; 창 이동·크기 변경을 따라가고 최소화·종료하면 떨어지는지
- PokeToken 관리 화면과 자체 제목 표시줄을 사용하는 다른 앱 창에서도 같은 착지가 가능한지
- 오래 실행하거나 다른 ‘항상 위’ 창을 띄운 뒤에도 펫을 클릭·잡을 수 있는지, 앞에 있던 작업 앱의 키보드 포커스를 빼앗지 않는지
- 짧게 클릭하면 관리 화면을 열지 않고 하트·쓰다듬기 동작과 캐릭터별 대사가 나오는지; 관리 화면은 메뉴바 또는 오른쪽 클릭 메뉴에서 열리는지
- 화면 배율이나 서로 다른 해상도의 모니터 사이를 여러 번 옮겨도 펫과 말풍선 크기가 늘어나거나 바닥 아래로 내려가지 않는지
- 다른 앱의 키보드 포커스가 걷는 펫에게 넘어가지 않는지
- 펫 주변의 투명한 배경에서 뒤에 있는 앱을 클릭할 수 있는지
- 메뉴바에서 보이기·숨기기·이동 일시정지·설정·종료가 동작하는지
- 실제 Claude Code·Codex 사용 후 사용량·성장이 증가하고, 종료 후 다시 실행해도 진행이 유지되는지
- 사용 중인 모니터·화면 배율, Spaces·전체 화면, 절전 복귀에서도 펫이 화면 안에 있는지
- 펫 위에 마우스를 둔 채 화면을 잠갔다 해제한 뒤, 다시 잡아 옮길 수 있는지; 잡고 있는 중 잠근 경우에도 복귀 후 새로 잡을 수 있는지

사용량은 10초 간격으로 확인하고 새 로그 파일은 60초 간격으로 찾습니다. **새로고침**으로 바로 확인할 수도 있습니다.

저장 위치는 `~/Library/Application Support/PokeToken Desktop`입니다. 테스트 결과를 전달할 때 프롬프트·응답·인증 파일을 보내지 않아도 됩니다. OS·칩과 재현 순서, 오류 메시지면 충분합니다.

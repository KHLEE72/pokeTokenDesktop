## 집계 규칙

- 일반/이로치/리전폼/특별한 모습/메가폼의 등록을 전국도감 종 번호로 합칩니다. 개체 수나 모습별 수집을 요구하지 않습니다. 메가스톤 구매만으로는 등록되지 않습니다.
- 같은 종을 여러 마리 사용하는 파티도 한 번의 종 등록으로 충족합니다. 스타팅·버전에 따른 파티 변형은 모두 합칩니다. 예를 들어 그린의 스타팅 분기는 이상해꽃·리자몽·거북왕을 모두 요구합니다.
- PWT는 실제 선출 3마리 대신 공개된 6종 후보 전체를 수집 목표로 삼았습니다. 무작위 배틀 시설의 전체 트레이너 풀을 추가로 요구하지 않습니다.
- 재대결의 레벨이 높더라도 파티 수는 줄어들 수 있습니다. 예를 들어 배틀샤토, 가라르 스타 토너먼트는 그 전투에서 쓰는 파티만 요구합니다. 서로 다른 전투의 파티를 임의로 섞지 않습니다.
- 알로라 시련은 주인 포켓몬과 가능한 SOS 동료를 합칩니다. 큰 시련은 해당 섬왕/섬여왕의 확인 가능한 강화 재대결을 우선하고, 없으면 큰 시련 파티를 사용합니다. 포니대협곡의 드래곤 시련을 하푸의 파티로 취급하지 않습니다.
- 알로라 시련 증표와 리그 칭호는 이 앱의 수집 보상입니다. 게임에서 해당 배지/칭호를 실제로 지급한다는 뜻은 아닙니다. 일반 시련에는 해당 Z크리스탈의 게임 도트, 큰 시련에는 해당 섬의 완료 스탬프를 표시합니다.
- 체육관·리그가 없는 레전드 아르세우스/Z-A와 외전의 트레이너는 이번 목록에 포함하지 않습니다.

## 저장과 전시

배지 그림은 `badge-art-catalog.json`에서 목표 ID별로 지정합니다. 같은 타입이어도 이슬의 캐스케이드배지·윤진의 레인배지·야청의 워터배지·곤포의 물 배지는 서로 다른 그림입니다. 실제 같은 배지를 주는 버전은 같은 그림을 공유합니다. 이름·타입으로 이미지를 추측하거나 타입 문양을 공통 배지로 사용하지 않습니다.

관동·성도는 게임별 원본 PNG, 호연/파이어레드·리프그린은 GBA 트레이너카드 도트, 신오는 플라티나의 원본 도트/팔레트를 사용합니다. 금·은/크리스탈의 관동 목표에는 하트골드·소울실버의 관동 도트를, BDSP에는 같은 신오 배지 디자인의 플라티나 도트를 적용합니다. 3DS 이후는 실제 배지 이미지를 원래 색과 외곽 형태로 표시합니다. 구세대 도트는 픽셀 렌더링, 현대 배지 그림은 부드러운 렌더링으로 표시하며 모두 `object-fit: contain`으로 비율을 보존합니다.

원본 URL·SHA-256·출처와 추출 영역/팔레트는 `scripts/badge-art-sources.json`과 생성 목록에 기록합니다. `python scripts/update-badge-art.py`(개발용 Pillow)로 로컬 PNG 136개를 재생성합니다. 앱에서는 다운로드 없이 199개 배지 목표의 카드·전시대·홈·사이드바에 같은 이미지를 표시합니다. 크레딧은 `public/licenses/Badge-art-credits.txt`로 동봉합니다.

`league-v1` 메타에 획득 시각·선택한 배지 ID 순서(최대 8개)·칭호 ID(최대 1개)를 저장합니다. 이전 도감은 시작 시 바로 인정하고, 새 수집은 성장/사용량 반영과 같은 트랜잭션에서 판정합니다. 전시를 해제하거나 언어를 바꿔도 획득 기록을 지우지 않습니다. 작품 간 배지를 자유롭게 섞을 수 있습니다.

자료를 수정할 때 기존 목표 ID를 재사용/재배열하지 말고 출처·전투 기준을 함께 검토하세요. `tests/league.test.ts`와 `npm run smoke:league`가 소급 인정·같은 종 중복 제거·요구 종·전시 제한·정렬·세 언어·재시작을 확인합니다.

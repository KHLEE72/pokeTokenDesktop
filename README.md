## 배지와 리그 칭호

**배지 · 리그 칭호**에서 관장 파티를 모아 배지를, 사천왕·챔피언 파티를 모아 칭호를 획득하세요. 22개 작품 묶음의 배지·시련 증표 199개와 리그 칭호 22개를 모을 수 있어요. 이미 등록한 도감도 인정하며, 일반·이로치·리전폼 중 어느 모습이든 같은 종이면 충족합니다.

재대결·최종 강화 파티가 기준이며 각 카드에서 요구하는 친구와 출처를 확인할 수 있어요. 알로라는 주인과 SOS 동료를 모으는 시련 증표, 섬왕·섬여왕의 큰 시련 증표로 여행을 기록합니다. 여러 작품에서 고른 **배지 최대 8개·칭호 1개**를 홈 상단에 전시하고 드래그·화살표로 순서를 바꾸세요.

<p align="center"><img src="docs/images/league-collection.png" width="1000" alt="작품별 배지 컬렉션과 최대 8개의 배지·칭호를 선택하는 전시대 예시"></p>

작품별 자세한 기준은 [수집 기준](docs/LEAGUE_CATALOG.md)을 참고하세요. 설정의 **앱 업데이트**에서 새 버전을 확인할 수 있으며, Windows 설치형은 다운로드 후 재시작하여 업데이트합니다. Portable과 현재 Mac 배포는 새 배포 파일을 내려받는 방식입니다. [업데이트 안내](docs/UPDATES.md)

## 처음 시작하기

1. **앱을 실행하세요.** 관리 화면과 화면 아래의 알이 나타납니다. 관리 화면을 닫아도 펫은 계속 함께해요.
2. **평소처럼 Claude Code·Codex를 사용하세요.** 기본 로그 폴더를 자동으로 찾습니다. 처음 연결한 과거 기록은 사용량에 표시하고, 연결 후 새로 쓴 토큰부터 성장에 반영합니다.
3. **함께할 친구를 골라보세요.** 홈의 **알 보관함**에서 타입을 선택하거나, **나의 도감**에서 만난 포켓몬을 꺼내세요. 다른 친구를 고르는 동안에도 이전 진행률은 보관됩니다.

첫 실행은 **English**로 시작합니다. **Settings → Display language**에서 한국어·English·日本語를 고르면 다음 실행에도 기억합니다.

### 어떤 알을 키워볼까요?

<p align="center">
  <img src="docs/images/egg-selection.png" width="820" alt="알 보관함을 펼쳐 풀타입 알·불꽃타입 알·물타입 알 등 18가지 타입 중 원하는 알을 선택하는 화면">
</p>

**알 보관함 → 알 선택하기**에서 원하는 타입을 고르세요. 보관 중인 알은 진행률부터 이어 키우고, 새 타입의 알은 0%부터 시작합니다. 어떤 친구가 태어날지는 부화할 때 확인하세요.

### 기록 폴더 직접 연결하기

**설정 → 토큰 사용 기록 연결 → 폴더 추가**에서 연결합니다. 수집 대상은 Claude Code·Codex의 **로컬 개발 로그**입니다.

| 도구 | 기본 폴더 | 추가할 폴더 |
| --- | --- | --- |
| Claude Code | `~/.claude/projects` | `projects` |
| Codex | `~/.codex/sessions` · `~/.codex/archived_sessions` | `sessions` · `archived_sessions` |

설정한 `CLAUDE_CONFIG_DIR`·`CODEX_HOME`이 있으면 해당 위치를 우선합니다. WSL은 `\\wsl.localhost\배포판\home\사용자\.claude\projects`처럼 Windows에서 읽을 수 있는 폴더를 선택하세요. 사용량은 주기적으로 확인하며 홈의 **새로고침**으로 바로 읽을 수도 있습니다.

## 성장과 수집

<p align="center">
  <img src="docs/images/pokedex.png" width="820" alt="보라시티 다크 도감에서 전설 뮤츠·환상 뮤·준전설 라티아스의 문장과 개체별 볼을 확인하는 화면">
</p>

**알 → 부화 → 진화 → 최종 진화.** 기본 선택인 ‘빠름’에서는 **50만 토큰**으로 부화합니다. 진화에 필요한 경험치는 홈의 성장 바에서 확인하세요.

| 지금 함께하는 모습 | 새 토큰은 어디로 갈까요? |
| --- | --- |
| 알 | 부화 경험치 |
| 성장 중인 현재 형태 | 다음 진화를 위한 경험치 |
| 최종 진화·이미 완성한 이전 모습 | 경험치사탕 |
| 진화 목표 선택을 기다리는 상태 | 경험치사탕 |

- **경험치사탕:** 10만 토큰당 1개, 1개당 10만 XP. 성장 중인 포켓몬에게 먹일 수 있고, 알에는 사용할 수 없어요.
- **이로치:** 부화 시 1/64 확률로 등장합니다. 일반·이로치 도감을 각각 선택하며 진화해도 이로치가 유지됩니다.
- **이브이:** 노말타입 알에서 만날 수 있어요. 홈의 **진화 목표**에서 8가지 진화형 중 하나를 고릅니다. 목표 없이 100%가 되면 선택할 때까지 기다립니다.
- **1~9세대:** 전국도감 No.001~1025의 기본 모습과 알로라·가라르·히스이·팔데아의 리전폼 57개를 만날 수 있어요. 전설·환상도 타입에 맞는 알에서 더 드물게 등장합니다.
- **분기 진화:** 킬리아·카르본처럼 진화형이 여럿이면 홈에서 목표를 고릅니다. 통신·돌·성별 등 원작 조건은 토큰 성장으로 대신해요. 진화가 없는 포켓몬은 부화 후 토큰을 사탕으로 모읍니다.
- **알의 타입:** 진화 계열의 첫 모습을 기준으로 합니다. 님피아를 만나려면 노말타입 알에서 이브이를 키우세요. 가로막구리는 가라르 지그제구리부터, 토오는 팔데아 우파부터 성장합니다. 리전폼을 지원하기 전에 얻은 독립 개체도 그대로 함께할 수 있어요.
- **추가 모습:** 도감 카드의 **다른 모습 · 메가진화**, 또는 도감의 **모습 · 메가진화** 탭에서 찾아보세요. 리전폼·메가폼과 진화에 필요한 특별한 모습 6개를 별도로 모으며, 기본 모습 1,025종의 수집과 기존 마스터볼 해금은 유지합니다.
- **성장 보관:** 포켓몬과 알을 바꿔도 진행 상태는 남습니다. 최종 진화 후에는 원하는 알이나 성장 중인 친구를 직접 골라주세요.
- **도감 탐색:** 세대·타입·상태로 좁혀 보고 이름·도감 번호로 검색하세요. 번호순·표시 언어의 이름순·획득순 정렬을 고를 수 있고 정렬 선택을 기억합니다. 획득순은 일반·이로치 각각 최근 처음 등록한 종부터, 미발견 종은 뒤에 표시합니다.
- **특별한 만남:** 준전설은 청록색 날개 문장, 전설은 금색 왕관, 환상은 별빛 문장으로 표시합니다. 분류 필터로 모아보세요. 준전설은 앱 안의 구분으로, 주요 전설 계열 이외의 전설 포켓몬을 뜻합니다. 망나뇽 같은 이른바 600족과는 구분해요.
- **최종 진화 기록:** 도감 안의 별도 탭에서 최근 기록부터 10마리씩 볼 수 있습니다. 오래된 기록도 페이지를 넘겨 확인하세요.

움직이는 도트 GIF가 있는 포켓몬은 GIF로, 나머지는 정적 도트 PNG로 표시합니다. 일반·이로치 이미지를 각각 캐시해 한 번 받은 모습은 오프라인에서도 볼 수 있어요.

### 메가진화와 메가스톤

<p align="center">
  <img src="docs/images/mega-evolution.png" width="820" alt="모습 도감에서 메가리자몽 X·Y와 영구 해금한 메가스톤을 확인하는 화면">
</p>

메가진화 가능한 모습을 도감에 등록하면, **모습 · 메가진화**에서 대응하는 메가스톤을 고를 수 있어요. **첫 해금 1개는 무료**, 이후에는 **경험치사탕 50개**로 영구 해금합니다. 일반·이로치와 대응하는 모든 개체가 해금을 공유하며, 변신할 때마다 사탕을 쓰지 않습니다.

해금한 카드의 **함께하기** 또는 홈의 모습 선택 메뉴에서 메가진화와 원래 모습을 바꿔보세요. 리자몽 X·Y처럼 다른 스톤은 각각 해금하며, 원래 성장 상태와 볼은 유지됩니다. 메가 상태의 새 토큰은 경험치사탕으로 쌓여요.

지원하는 메가폼은 97개이며, 메가스톤 92종과 레쿠쟈의 **화룡점정** 해금 1종으로 구성됩니다. 레쿠쟈도 같은 무료 1회·사탕 50개 규칙을 사용합니다. 영원의 꽃 플라엣테 등 특정 모습이 필요한 경우에는 그 모습을 먼저 만나야 해요. 메가지가르데는 도트 이미지 대신 일반·이로치의 공식 일러스트를 표시합니다.

### 친구마다 다른 인사

대사는 공식 도감의 생태와 행동을 참고해 새로 쓴 문장입니다. 따라큐는 천을 들추지 말아 달라고 부탁하고, 앱솔은 위험을 미리 알리며, 잠만보는 밥과 낮잠을 챙겨요. 가디안은 마음을 헤아리고, 두드리짱은 망치를 먼저 챙깁니다. 잡기·낙하·착지·쓰다듬기도 몸의 특징에 맞춰 반응하며, 한국어·영어·일본어 모두 로컬에서 동작합니다.

## 내 컴퓨터에 남는 기록

사용량과 성장 상태는 내 컴퓨터에 저장합니다. 대화 본문·인증 정보는 저장하거나 전송하지 않으며, 펫의 대사는 로컬에서 골라요. 별도의 AI 호출은 없습니다. 포켓몬 이미지는 처음 받을 때 다운로드하고 이후 캐시를 사용합니다.

수동으로 백업하려면 앱을 종료한 뒤 아래 폴더 전체를 복사하세요.

| Windows | macOS |
| --- | --- |
| `%APPDATA%\PokeToken Desktop` | `~/Library/Application Support/PokeToken Desktop` |
